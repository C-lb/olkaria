# Credits

Every file under `host/art/assets/` comes from one of the packs below, and each section lists the files taken from it. The class figures, tiles, exhibit, gate, digits font and the four bosses are drawn in code (`host/art/placeholders.ts` and `host/art/bosses.ts`) and need no credit.

## Superpowers backgrounds asset pack

Made by Pixel-boy at Sparklin Labs for Superpowers, published at https://github.com/sparklinlabs/superpowers-asset-packs (commit e8674a0, folder `backgrounds/layers`).

Licence: Creative Commons Zero 1.0 Universal (CC0 1.0), as stated in LICENSE.txt at the root of that repository (https://github.com/sparklinlabs/superpowers-asset-packs/blob/master/LICENSE.txt). Attribution is not required; it is given here anyway.

Files used, both recoloured to the game's stone palette with the moon dimmed, otherwise unchanged:

- `host/art/assets/backdrop/night-sky.png`, from `backgrounds/layers/89.png` (the night sky with clouds and the moon).
- `host/art/assets/backdrop/storm-hill.png`, from `backgrounds/layers/84.png` (the hill with the haunted castle and the bare trees).

Files used:
